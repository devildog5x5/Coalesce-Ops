# Coalesce Ops

One practice for joining separate teams, systems, and sites into a single operation.

Open `index.html` locally, or unzip the zip into Hostinger `public_html`.

**Hostinger zip:** `CoalesceOps-1.1.0.zip` — unzip into `public_html` (files at the zip root, forward-slash paths). Rebuild with `powershell -File .\build_site_zip.ps1` (filename includes the version from `VERSION`). Footer on every page: Coalesce Ops v1.1.0.
